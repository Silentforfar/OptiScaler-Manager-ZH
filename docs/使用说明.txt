OptiScaler 安装管理器
======================

这是什么
--------

给「OptiScaler-DLSSNR v0.2.0 中文版」用的图形安装器。它解决四件事：

1. 自动找游戏 —— 扫描 Steam / Epic / GOG 的库目录，列出所有装了游戏的位置。
2. 帮你选对注入目标 —— 列出一个游戏目录下所有可注入的 exe，标出推荐项，
   并自动把安装目录切到该 exe 所在的文件夹。
3. 一键安装 —— 把 OptiScaler 全套文件（含 40 系 4X 多帧生成插件、中文 ini、
   中文说明）复制进去，按代理名把主程序改名。目标目录已有同名文件会先备份。
4. 无损卸载 —— 只删自己装进去的文件，把安装时备份的原文件原样放回。


最重要的一件事：注入目标选哪个 exe
----------------------------------

OptiScaler 是代理 DLL，**只有放在「真正加载图形 API 的那个 exe」旁边才会生效**。
放在启动器旁边、或者放在游戏的上一级目录，装了也不会起作用 —— 这是最常见的失败原因。

选错的典型情况：

  · 游戏有启动器 / HQ 平台
    比如 Call of Duty HQ：根目录 cod.exe 是入口，真正跑游戏的是
    sp26\sp26-cod.exe（BO6 战役是 sp24\sp24-cod.exe，
    BO6 本体是 cod24\cod24-cod.exe）。装在根目录对某些模式无效。

  · 虚幻引擎游戏
    主程序在 Binaries\Win64\ 下面，通常叫 XXX-Win64-Shipping.exe。
    不要装在 Engine\ 里面，也不要装在项目根目录。

  · 目录层级很深的游戏
    比如赛博朋克在 bin\x64\ 下。

本工具的做法：选中一个游戏后，会把该目录下（最多往下 4 层）所有体积像样的 exe
列进「游戏主程序（注入目标）」下拉框，按可能性排序。

  判据包括：是否 UE 的 *-Win64-Shipping.exe、是否在 Binaries 下、体积、
  层级深度、名字里有没有 launcher / crashhandler / installer 之类的辅助特征。

列表里的标注含义：

    UE 主体     虚幻引擎的 Shipping 主程序，基本就是它
    子模块      子目录名出现在文件名里（sp26\sp26-cod.exe），某个模式的本体
    启动器      名字里有 launcher，通常不是注入目标
    辅助程序    安装器、崩溃上报、下载器之类，别选

默认选中的只是推荐，不是你玩的那个。一款游戏有多个模式、多个 exe 时，
请按你实际要玩的那个模式去选 —— 选中后「安装目录」会自动跟着变，
确认框里也会显示完整的 exe 路径，装之前核对一眼最稳。


怎么用
------

双击 OptiScalerManager.exe（旁边的 _internal 文件夹必须保留）。

安装：
  1. 切到「安装新游戏」
  2. 点「扫描游戏平台」，或「手动选择游戏目录」选到游戏根目录
  3. 选中游戏 → 右侧「游戏主程序」下拉里确认注入目标
  4. 代理文件名保持 dxgi.dll（Vulkan 游戏选 winmm.dll）
  5. 点「安装到该目录」

进游戏后：
  · 进入真正的游戏画面（不是设置菜单）后按 Insert 打开中文菜单
  · 40 系多帧生成：按 Backspace 打开 MFG 解锁器菜单，选 2X / 3X / 4X

卸载：
  「已安装」页 → 选中 → 卸载所选。文件删掉、备份还原。


几个说明
--------

· 已经装过的目录会拒绝重复安装，先卸载再装。
· 「校验完整性」比对每个文件的 SHA-256。ini 显示「已改动」是正常的
  （你自己调过设置），只有「缺失」需要处理。
· 记录写在两处：%LOCALAPPDATA%\OptiScalerManager\installed.json 和
  游戏目录里的 .optiscaler_manifest.json，卸载以 manifest 为准。
· 卸载不做任何猜测：找不到 manifest 就直接拒绝。


装完之后还要做的三件事
----------------------

1. 中文字体
   ini 已配好 UseHQFont=true 和 TTFFontPath=C:\Windows\Fonts\simhei.ttf。
   如果菜单里中文是问号，改成 C:\Windows\Fonts\msyh.ttc 再试。

2. 神经渲染的模型文件
   安装包里已经带了 nvngx_dlssnr.dll（158 MB），安装时会一起复制到游戏目录，
   不用再手动放。
     · 目标目录里已有同尺寸的模型文件时，会保留你原来那份，不覆盖；
       卸载时也不会删除它。
     · 这个模型是 NVIDIA 官方版（版本信息里是 DVS PRODUCTION），
       只有 RTX 50 系能真正跑起来。40/30/20 系需要换成社区修改版，
       换好后重新装一次即可。
     · 它是你自己的驱动文件，别随安装包公开分发。

3. 在线游戏注意
   OptiScaler 是注入型工具，带反作弊的联机游戏有封号风险。要测先用单机游戏。


目录结构
--------

  OptiScalerManager.exe      主程序
  _internal\                 运行库与 payload（必须保留）
  _internal\payload\         真正会被装进游戏的那套文件（含 158 MB 模型）


回退
----

本程序本身不改动系统，删掉整个文件夹即可卸载它自己。
装进游戏的 OptiScaler 请在「已安装」页正规卸载。

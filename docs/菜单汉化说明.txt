游戏内菜单汉化说明
====================

做了什么
--------

OptiScaler.dll 里游戏内菜单的文字已全部替换成简体中文，共 **776 条**：

- 主菜单各页（超分器 / FSR / XeSS / DLSS / 帧生成 / 按键绑定 / 伪装 / 日志 / 放大镜等）
  的开关名、下拉选项、分组标题、悬停说明
- DLSS 神经渲染整页的参数说明（细节强度、色彩强度、高光保护、纸白、曝光校准那一整套）
- 状态提示、报错信息

没有翻译的，是本来就不该翻的：dll 文件名、ini 键名、模型标识（MODEL_3/4/5/6、KPSS、SPLAT）、
DX12 资源状态枚举、ImGui 自身内部键名表、以及 `FSR 3 FG`、`FFX + Enabler` 这类纯技术代号。

怎么做到的
----------

菜单是 ImGui 画的，文字硬编码在 DLL 的只读数据里。中文一个字符占 3 字节，英文一个字母占 1 字节，
像 `Skip Reset` 这种短标签根本塞不下"跳过重置"，所以没有原地覆盖：

1. 在 DLL 末尾新增了一个 `.zh` 节，把所有中文串放进去
2. 把代码里 958 处指向旧英文串的引用（`lea reg,[rip+disp32]`）改指到新位置
3. 另有 37 处存在数据段的字符串指针，一并改写（已确认全部带重定位项，基址变化也不会错）

静态校验结果：旧地址引用清零、PE 结构合法、解析告警数与原件完全一致（124 条，一条没多）。


字体：必须保持这两行
--------------------

  [Menu]
  UseHQFont=true
  TTFFontPath=C:\Windows\Fonts\simhei.ttf

OptiScaler 自带的 Hack-Regular 不含汉字，必须换成系统中文字体，否则中文会显示成问号或空白。
这份 ini 里已经配好了黑体。如果系统里没有 simhei.ttf，可改成：

  TTFFontPath=C:\Windows\Fonts\msyh.ttc      （微软雅黑）

注意 `UseHQFont` 必须是 `true`，为 false 时不会加载这个字体。


唯一还没验证的事
----------------

ImGui 1.92 用的是动态字体图集，理论上只要字体里有汉字就能画出来。这一点没法离线验证，
只能进游戏看一眼：

  按 Insert 打开菜单 → 任一页面

- 看到汉字：一切正常，不用管了
- 看到 ??? 或方块：说明字体图集没有加载汉字字形。
  先把 TTFFontPath 换成 msyh.ttc 试一次；还不行就是后端限制，需要改字体加载逻辑，
  到时候把 OptiScaler.log 发我。
- 菜单打不开或游戏崩溃：把同目录下的 OptiScaler.dll.orig 改名覆盖 OptiScaler.dll，立刻恢复。


回退
----

文件夹里保留了原始英文版 OptiScaler.dll.orig，重命名覆盖即可回到英文菜单。
